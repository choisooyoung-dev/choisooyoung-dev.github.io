Shopee Open API로 주문 목록/상세 조회하기

Shopee Open API의 주문 목록(get_order_list)과 주문 상세(get_order_detail) 조회 API를 코드로 정리한다.

게시 2026/08/27
By Sooyoung Choi
읽는 시간 5분

앞선 글에서 발급받은 access_token으로, 실제 주문 데이터를 가져와본다.

Shop API는 서명 방식이 조금 다르다

앱 인증/토큰 발급 때 썼던 공개(Public) API는 partner_id + path + timestamp만으로 서명했다. 하지만 주문 조회처럼 특정 샵의 데이터를 다루는 Shop API는 여기에 access_token과 shop_id가 추가로 들어간다.

import crypto from "crypto";

const PARTNER_ID = Number(process.env.SHOPEE_PARTNER_ID);
const PARTNER_KEY = process.env.SHOPEE_PARTNER_KEY!;

// Shop API 서명: partner_id + path + timestamp + access_token + shop_id
function signShopApi(
  path: string,
  timestamp: number,
  accessToken: string,
  shopId: number
): string {
  const baseString = `${PARTNER_ID}${path}${timestamp}${accessToken}${shopId}`;
  return crypto
    .createHmac("sha256", PARTNER_KEY)
    .update(baseString)
    .digest("hex");
}

앱 인증 단계에서 썼던 sign()(public API용)과 헷갈리지 않게, 별도 함수(signShopApi)로 분리해두는 걸 추천한다.

1. 주문 목록 조회 (get_order_list)

import axios from "axios";

interface GetOrderListParams {
  accessToken: string;
  shopId: number;
  timeFrom: number; // unix timestamp
  timeTo: number;
  cursor?: string;
}

export async function getOrderList({
  accessToken,
  shopId,
  timeFrom,
  timeTo,
  cursor = "",
}: GetOrderListParams) {
  const path = "/api/v2/order/get_order_list";
  const timestamp = Math.floor(Date.now() / 1000);
  const signature = signShopApi(path, timestamp, accessToken, shopId);

  const { data } = await axios.get(`https://partner.shopeemobile.com${path}`, {
    params: {
      partner_id: PARTNER_ID,
      timestamp,
      access_token: accessToken,
      shop_id: shopId,
      sign: signature,
      time_range_field: "create_time", // create_time | update_time
      time_from: timeFrom,
      time_to: timeTo,
      page_size: 50, // 최대 100
      cursor,
    },
  });

  return data;
  // data.response.order_list: [{ order_sn, order_status }, ...]
  // data.response.more: 다음 페이지 존재 여부
  // data.response.next_cursor: 다음 페이지 조회용 커서
}
  • time_from ~ time_to는 최대 15일 범위까지만 조회 가능하다 (그 이상은 구간을 나눠서 여러 번 호출해야 한다).
  • 응답이 많으면 more: true와 함께 next_cursor가 오는데, 이 값을 다음 요청의 cursor에 넣어서 페이지네이션한다.

export async function getAllOrderSns(
  accessToken: string,
  shopId: number,
  timeFrom: number,
  timeTo: number
): Promise<string[]> {
  const orderSns: string[] = [];
  let cursor = "";

  while (true) {
    const { response } = await getOrderList({
      accessToken,
      shopId,
      timeFrom,
      timeTo,
      cursor,
    });

    orderSns.push(...response.order_list.map((o: any) => o.order_sn));

    if (!response.more) break;
    cursor = response.next_cursor;
  }

  return orderSns;
}

2. 주문 상세 조회 (get_order_detail)

export async function getOrderDetail(
  accessToken: string,
  shopId: number,
  orderSnList: string[]
) {
  const path = "/api/v2/order/get_order_detail";
  const timestamp = Math.floor(Date.now() / 1000);
  const signature = signShopApi(path, timestamp, accessToken, shopId);

  const { data } = await axios.get(`https://partner.shopeemobile.com${path}`, {
    params: {
      partner_id: PARTNER_ID,
      timestamp,
      access_token: accessToken,
      shop_id: shopId,
      sign: signature,
      order_sn_list: orderSnList.join(","), // 한 번에 최대 50개
      response_optional_fields:
        "item_list,total_amount,recipient_address,buyer_username",
    },
  });

  return data.response.order_list;
}
  • order_sn_list는 한 번에 최대 50개까지만 넣을 수 있다. 50개 넘으면 잘라서 여러 번 호출해야 한다.
  • response_optional_fields로 필요한 필드만 골라서 요청할 수 있다 — 안 쓰는 필드까지 다 받아오면 응답이 쓸데없이 커지니, 실제 쓰는 필드만 지정하는 게 좋다.

export async function fetchOrders(
  accessToken: string,
  shopId: number,
  timeFrom: number,
  timeTo: number
) {
  const orderSns = await getAllOrderSns(accessToken, shopId, timeFrom, timeTo);

  // 50개씩 끊어서 상세 조회
  const chunks: string[][] = [];
  for (let i = 0; i < orderSns.length; i += 50) {
    chunks.push(orderSns.slice(i, i + 50));
  }

  const results = [];
  for (const chunk of chunks) {
    const detail = await getOrderDetail(accessToken, shopId, chunk);
    results.push(...detail);
  }

  return results;
}

정리

  • Shop API는 서명에 access_token, shop_id가 추가로 들어간다 (Public API 서명과 다름).
  • 주문은 목록(order_sn만) → 상세(실제 데이터) 두 단계로 나눠서 가져온다.
  • get_order_list는 최대 15일 범위, get_order_detail은 한 번에 최대 50개 order_sn 제한이 있으므로 큰 범위/많은 주문을 다룰 땐 구간 분할 + 페이지네이션 + 청크 처리가 기본이다.
