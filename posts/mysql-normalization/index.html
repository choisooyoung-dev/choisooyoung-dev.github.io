MySQL 정규화, 역정규화

MySQL 정규화와 역정규화 개념을 이상 현상(삽입/갱신/삭제) 예시, 정규화 단계(1NF~3NF), 비교표로 정리한다.

게시 2026/08/25
By Sooyoung Choi
읽는 시간 6분

테이블을 설계할 때 늘 고민하게 되는 정규화(Normalization)와 역정규화(Denormalization)를 정리해본다.

정규화 (Normalization)

데이터 중복을 없애서 갱신 이상(Anomaly)을 방지하는 테이블 설계 원칙. 하나의 정보는 한 곳에만 저장하고, 나머지 테이블에서는 그 정보를 참조(FK)하게 만드는 게 핵심이다.

정규화를 안 하면 생기는 문제 (이상 현상)

종류 설명 예시
삽입 이상 (Insert Anomaly) 불필요한 데이터까지 같이 넣어야 저장이 가능한 상황 학생이 없는데 강의 정보만 등록하고 싶어도 학생 컬럼이 필수라 등록 불가
갱신 이상 (Update Anomaly) 중복 저장된 값 중 일부만 바뀌어서 데이터 불일치 발생 고객 주소를 주문 테이블마다 저장 → 고객이 이사해도 과거 주문 행들은 옛 주소로 남음
삭제 이상 (Delete Anomaly) 한 행을 지웠는데 의도치 않게 다른 정보까지 같이 사라짐 마지막 주문 하나를 지웠더니 그 고객의 주소 정보 자체가 통째로 사라짐

EX) 주문 테이블에 매번 고객 주소를 같이 기입 → 고객이 주소를 변경 → 이미 저장된 과거 주문 행들에는 반영이 안 됨 (갱신 이상)

해결 방법

  • customerId 같은 식별자만 주문 테이블에 남기고, 주소 같은 상세 정보는 customer 테이블로 따로 뺀다.
  • 이후엔 FK(customerId)로 조인해서 주소를 조회 → 주소는 customer 테이블 딱 한 곳에서만 관리되므로 변경 시 모든 주문에 자동으로 반영된 것처럼 조회된다.

정규화 단계 (간단 정리)

  • 1NF: 컬럼 값이 원자값(더 이상 쪼갤 수 없는 값)이어야 함 — 한 컬럼에 여러 값을 콤마로 넣지 않기
  • 2NF: 1NF를 만족하면서, 기본키의 일부에만 종속되는 컬럼(부분 함수 종속)을 제거
  • 3NF: 2NF를 만족하면서, 기본키가 아닌 컬럼이 다른 일반 컬럼에 종속되는 것(이행 종속)을 제거

실무에서는 보통 3NF 정도까지만 맞추고, 그 이상(BCNF 등)은 상황에 따라 판단한다.

역정규화 (Denormalization)

조회 성능을 위해, 정규화로 쪼개놓은 데이터를 일부러 다시 중복 저장하는 것. JOIN이 너무 잦고 무거워서 조회 성능이 떨어질 때 고려한다.

EX) 주문 통계 화면에서 매번 SUM(price)로 총 주문 금액 계산 → 주문 건수가 많아질수록 매번 전체를 훑어야 해서 성능 저하

해결 방법

  • 집계값(SUM)을 미리 계산해서 별도 컬럼/테이블에 중복 저장해둔다.
  • 조회할 땐 그 저장된 값을 그냥 읽기만 하면 되므로 빠르다.

Trade-off

  • 저장해둔 값과 원본 데이터가 어긋나지 않으려면, 주문이 추가/수정/삭제될 때마다 중복 저장된 값도 같이 갱신해줘야 한다.
  • 즉 읽기(조회) 성능은 좋아지지만, 쓰기(갱신) 로직이 복잡해지고 데이터 일관성 관리 부담이 커진다.

trade-off: 하나를 얻으면 하나를 포기해야 하는 관계. 여기서는 “조회 속도” ↔ “데이터 일관성/쓰기 복잡도”의 트레이드오프.

역정규화를 고려하는 경우

  • 통계/대시보드처럼 집계 조회가 매우 잦고, 실시간성이 크게 중요하지 않은 경우
  • JOIN 비용이 실제로 병목으로 확인된 경우 (막연히 “느릴 것 같다”가 아니라 측정 후 판단)
  • 캐시나 배치(batch)로 집계값을 갱신하는 방식으로 일관성 부담을 줄일 수 있는 경우

정리

  정규화 역정규화
목적 데이터 무결성 유지, 중복 제거 조회 성능 향상
장점 갱신 이상 방지, 저장 공간 절약 JOIN 감소로 조회 빠름
단점 JOIN이 많아져 조회가 느려질 수 있음 중복 데이터 관리(갱신) 부담, 일관성 깨질 위험
우선순위 기본적으로 정규화부터 성능 문제가 실측으로 확인된 부분만 부분적으로 역정규화

결론적으로 기본은 정규화로 설계하고, 실제로 성능 문제가 확인된 부분에 한해 선택적으로 역정규화를 적용하는 게 일반적인 접근이다.
